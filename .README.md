
# Nail Onns

A nail salon booking demo built with React and Node.js.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
npm install
npm run dev
```

## Local URLs

- Frontend: http://localhost:5173
- Backend: http://localhost:5000
- API health: http://localhost:5000/api/health
- Services: http://localhost:5000/api/services

## Note

Bookings are held in memory for demonstration only.
